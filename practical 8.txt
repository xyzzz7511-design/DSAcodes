def heapify(arr, n, i):
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2

    if left < n and arr[left] > arr[largest]:
        largest = left

    if right < n and arr[right] > arr[largest]:
        largest = right

    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)


def heap_sort(arr):
    n = len(arr)

    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)

    print("Max-heap built:", arr)

    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]
        heapify(arr, i, 0)
        print("After moving", arr[i], "to end:", arr)


numbers = [12, 11, 13, 5, 6, 7]

print("Original array:", numbers)

heap_sort(numbers)

print("Sorted array:", numbers)



Title::::

Implementation of Heap Sort Using Python.

Theory:::::

Theory
Heap Sort is a comparison-based sorting algorithm that uses a binary heap data structure.
A heap is a complete binary tree that satisfies the heap property.
There are two types of heaps:
Max Heap: Parent node is greater than or equal to its children.
Min Heap: Parent node is smaller than or equal to its children.
For sorting elements in ascending order, Heap Sort generally uses a Max Heap.
The largest element is repeatedly moved to the end of the array until all elements are sorted.

Algorithm::::::::

Start.
Read the array elements.
Build a Max Heap from the given array.
Swap the root element with the last element.
Reduce the heap size by one.
Apply heapify to maintain the Max Heap property.
Repeat until the heap size becomes one.
Display the sorted array in ascending order.
Stop.

Conclusion :::::
Thus, the Heap Sort algorithm was successfully implemented using Python. The given array was sorted in ascending order using a Max Heap with O(n log n) time complexity.
